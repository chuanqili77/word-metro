# Browser review

Production GitHub Pages, Chromium. Two independent, in-memory Demo wallets used the hosted Studionet faucet. The host published the race and could close it, while its route submission control was disabled. A second wallet edited and signed missing and certified routes. A visitor opened the shared race URL and inspected both outcomes and the supporting Wiktionary entries.
